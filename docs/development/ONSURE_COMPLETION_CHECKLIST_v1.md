## 최종 잠금

최종 후보 조건을 충족해도 최종 잠금은 자동 허용하지 않는다. 별도 승인·독립 감사·최종 영수증 검증이 필요하다.

```text
현재 개발 상태      IMPLEMENTED_NOT_RUN
개발 관문           HOLD
최종 후보           BLOCKED
최종 잠금           NOT_ALLOWED
```
