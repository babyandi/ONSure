# ONSURE 제품 기준선

## 1. 제품 정체성

ONSURE는 등록된 AI 프로그램을 자동 학습하고, 실제 수행 결과를 반복 검증하며, 발견된 결함과 부족한 부분을 자동 보완 개발하는 독립형 상용 소프트웨어입니다.

ONSURE의 본질은 검증기 하나가 아니라 다음의 폐쇄 루프입니다.

```text
학습 → 검증 → 진단 → 보완 → 재검증 → 개선 입증 → 경험 축적
```

## 2. 해결하려는 문제

AI 프로그램은 코드가 실행된다는 사실만으로 신뢰할 수 없습니다. 동일 코드라도 모델, 프롬프트, 검색 데이터, 도구, 문맥과 설정에 따라 결과가 달라집니다. 대부분의 조직은 다음 문제를 겪습니다.

- 프로그램의 실제 목적과 정상 동작이 명확히 정리되지 않음
- 테스트가 정상 경로에 편중되고 경계·실패·적대 상황이 누락됨
- 코드, 프롬프트, RAG, 도구 계약의 변경 영향이 분리되어 관리됨
- AI가 수정한 결과가 실제로 개선됐는지 증명하기 어려움
- 같은 실패와 수정 경험이 프로젝트마다 반복 소모됨
- 일반 사용자는 AI 코딩 결과를 독립적으로 검토하기 어려움

## 3. 제품 가치

ONSURE는 대상 AI 프로그램마다 다음 자산을 구축합니다.

- Program Model: 목적, 구성, 의존성, 규칙과 인터페이스
- Behavior Model: 성공·실패·변동·취약 조건
- Baseline: 기대 동작과 허용 범위
- Failure Memory: 재현 조건, 원인, 영향, 수정 및 회귀 시험
- Improvement Memory: 수정 전후 효과와 재사용 가능한 개선 패턴
- Evidence Ledger: 실행 명령, 입력, 환경, 결과와 판정 근거

## 4. 제품 경계

### 수행하는 것

- AI 프로그램 등록과 자동 분석
- 프로그램·행동·개선 학습
- 정상·경계·실패·적대 시나리오 생성
- 기능·정확성·보안·정책·AI 행동 검증
- 근본원인 분석과 변경 영향 분석
- 코드·프롬프트·RAG·도구·설정·테스트 보완
- 수정 전후 비교와 회귀검증
- 패치·브랜치·PR·보고서 생성

### 수행하지 않는 것

- 기업 전체 지식과 업무를 범용적으로 학습하는 플랫폼
- 기반모델의 대규모 사전학습
- 신규 시스템 전체를 자유롭게 개발하는 범용 코딩 에이전트
- 프로젝트·조직·성과·운영 관제를 총괄하는 전사 플랫폼
- 일반 문서·디자인·보고서 제작 제품

## 5. 독립성 원칙

- ONSURE는 ORUDA와 별도 제품입니다.
- ONSURE는 ORUDA의 저장소, 정책, 실행환경, 데이터와 기능에 의존하지 않습니다.
- ONSURE는 단독 설치, 실행, 라이선스, 판매와 고객 지원이 가능해야 합니다.
- 향후 ORUDA가 ONSURE 기능을 포함하더라도 Standalone 제품을 기준 구현으로 유지합니다.
- ORUDA 전용 명칭, 경로, 역할과 계약은 ONSURE 핵심 기준선에 포함하지 않습니다.

## 6. 제품 성공 기준

제품의 성공은 단순 발견 건수나 테스트 통과 수가 아니라 다음으로 판단합니다.

- 등록 후 프로그램 모델을 자동 생성할 수 있는가
- 기존 테스트가 놓친 결함을 재현 가능한 형태로 발견하는가
- 수정 전후 품질 향상을 수치와 증거로 입증하는가
- 기존 정상 동작의 회귀를 차단하는가
- 동일 실패가 반복될수록 탐지와 수정 효율이 높아지는가
- 비개발자도 결과와 위험을 이해할 수 있는가
- 개발자는 패치와 재현 절차를 즉시 사용할 수 있는가
