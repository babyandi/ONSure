SAMPLE · NONFINAL · NOT AUTHORITY

DESIGN REVIEW ASSET

예외 상태가 성공처럼 보이지 않는지 비교

모든 값은 시각 설계용 샘플이며 Core 사실이 아니다.

NORMAL_KNOWN
TESTED

권위 있는 현재 상태가 존재한다. 이 값 자체가 최종 승인이나 Production GO를 뜻하지 않는다.

State와 finality를 분리한다.
LOADING
데이터 확인 중

Skeleton만 표시하고 임시 숫자·임시 PASS·샘플 Assurance 상태를 넣지 않는다.

Fake placeholder value 금지.
EMPTY
연결된 증적 없음

조회가 성공했고 authoritative collection이 비어 있는 경우에만 사용한다.

EMPTY ≠ UNKNOWN ≠ NOT_AVAILABLE.
UNKNOWN
확인되지 않음

Core가 현재 사실을 확정할 수 없는 상태다. 상위 상태로 추정하지 않는다.

성공색·체크마크 금지.
NOT_RUN
검증 미실행

필요한 실행이 아직 수행되지 않았다. 0건 성공이나 미발견으로 표현하지 않는다.

NOT_RUN은 PASS가 아니다.
INCONCLUSIVE
판정 불충분

실행은 있었지만 결과가 충분하지 않아 결론을 낼 수 없다.

FAIL/PASS로 강제 변환 금지.
HOLD
진행 보류

정책·근거 부족·불명확 상태로 다음 단계 진행을 멈춘다. 단순 로딩처럼 보이면 안 된다.

보류 사유 drill-down 필요.
STALE
증적 갱신 필요

현재 Source/Revision과 증적 기준선이 달라졌다. 이전 결과를 현재 판정으로 표시하지 않는다.

Source revision 비교는 Core authority.
FAILED
검증 실패

실패 대상과 검증 범위를 함께 보여준다. 전체 제품 실패로 과장하지 않는다.

예: Runtime verification: FAILED.
CORE_UNAVAILABLE
Core 상태 사용 불가

권위 상태를 읽지 못했다. 캐시가 있더라도 현재 권위 값처럼 조용히 대신 보여주지 않는다.

Fail-closed presentation.
UNAUTHORIZED
리소스를 표시할 수 없음

권한이 없으며, 다른 Tenant나 보호 리소스의 존재 여부를 불필요하게 노출하지 않는다.

Resource existence leakage 방지.
POLICY_BLOCKED
정책 조건 미충족

리소스는 볼 수 있지만 SoD, stale revision 또는 필수 증적 조건 때문에 특정 행동이 차단된다.

Permission denied와 구분.
NONFINAL
독립 검증 미완료

현재 화면이나 일부 검증 결과가 존재해도 전체 최종 판정이 아님을 나타낸다.

한 화면에 반복 경고 남발 금지.
PASSED_BOUNDED
Runtime verification: PASSED

특정 검증의 bounded result만 성공이다. 단독 `PASS` 배지는 사용하지 않는다.

Subject + test type를 항상 명시.
