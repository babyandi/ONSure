# ONSure Remediation 자산

이 디렉터리는 PR #28 통합 Remediation에서 실제 사용한 이미지와 시각 자산의 Git 정본 위치다.

현재 코드·검증 작업에는 사용된 이미지가 없으므로 이미지 파일을 임의 생성하거나 복제하지 않았다. `manifest.v1.json`의 `assets` 배열이 빈 것이 현재 정본 상태다.

이미지를 추가할 때는 원본 파일을 이 디렉터리에 저장하고 다음 값을 Manifest에 함께 기록한다.

- 안정 Asset ID
- 저장소 상대 경로
- SHA-256
- MIME type와 픽셀 크기
- 출처 및 작성자
- 라이선스 또는 내부 사용권
- 사용 목적과 연결 문서/화면
- 추가 일시와 검증 상태

Codex는 Manifest에 등록되지 않은 이미지, 외부 URL만 존재하는 이미지, 출처·사용권이 불명확한 이미지를 제품 자산으로 사용하면 안 된다.
